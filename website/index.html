Keep the session.

tmux-backed terminals keep running when you close a panel or quit the app. Reopen Super Terminal and reconnect to your work.

Your agent CLIs keep their existing permissions. Conductor uses your Codex sign-in; model requests send work context to that provider.

Make yourself at home

Build it.
Open it. Get to work.

Super Terminal is available to build from source on macOS. Start with the public repository.

  • macOS Ventura or later
  • Node.js 22.13+, npm, Python 3, and tmux
  • Your preferred agent CLIs, installed and signed in
Read the installation documentation
Terminal · macOS
git clone https://github.com/NikoKaranatsios/super-terminal.git
cd super-terminal
brew install tmux
npm install
npm run install:desktop
open "$HOME/Applications/Super Terminal.app"

Source build · No prebuilt release is published.
The macOS app is ad hoc signed, not notarized.
